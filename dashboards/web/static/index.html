2 or 3 devices flood the line: a real jam. The agent should slow a flooder.
congest border
1 device floods at 5 to 9 Mbit/s: sometimes a jam.
fault wan
The internet cable gets slow. The line is not full, so the trust check should refuse.
fault devlink
One protected device's own cable fails. The trust check should refuse and name it.
stopflood, stopfault
